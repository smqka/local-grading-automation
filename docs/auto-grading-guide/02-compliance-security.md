# 合规和安全边界

## 数据分类

默认按较高敏感度处理阅卷数据：

- 学生答案截图可能包含身份信息、笔迹、成绩和学习表现。
- AI 建议分可能影响评价，应保留人工审核空间。
- API key、模型网关地址、图片托管 key 均属于敏感配置。

## 默认原则

- 只捕获用户主动选择的窗口。
- 只裁剪当前题目答案区域。
- 不把 API key 写入前端代码。
- 不提交 `.env`、日志、真实答案图和阅卷系统截图。
- 不保存第三方阅卷系统账号、密码、cookie 或 token。
- 不绕过验证码、风控、权限校验或平台限制。

## 图片上传边界

默认优先使用模型接口直接支持的 base64 图片输入。若使用图片 URL 模式：

- 明确告知图片会上传到第三方或自有文件服务。
- 优先使用自有对象存储和短期有效链接。
- 不把上传图片用于训练、宣传或长期保存。
- 正式使用前确认组织内部数据和第三方工具政策。

## 自动点击安全

- 自动点击只能由本机服务执行。
- 服务默认绑定 `127.0.0.1`。
- 用户必须主动启用自动点击。
- 坐标必须由用户记录。
- 模型返回前不得点击。
- 低置信度默认建议等待审核。

## 发布前检查

- `.env` 未提交。
- `logs/` 未提交。
- `__pycache__/` 未提交。
- 文档中没有私人路径。
- 仓库中没有真实学生图片或阅卷系统截图。
- `.env.example` 只包含占位符。
