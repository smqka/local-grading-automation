# 合规与安全设计

本文件不是法律意见。正式上线或给学校使用前，需要由学校、平台方或专业人士确认合规要求。

## 合规原则

默认按高敏感度处理学生答题数据：

- 学生答题图片可能包含姓名、班级、学号、笔迹和成绩信息。
- 未成年学生相关信息需要更严格保护。
- AI 评分结果会影响学生评价，应保留人工确认和申诉空间。
- 工具应坚持最小必要、目的限定、可追溯、可删除。

## 数据分类

| 数据 | 风险 | 默认处理 |
| --- | --- | --- |
| 学生答题区域图片 | 高 | 只裁剪答案区域，默认不长期保存 |
| 学生姓名/班级/学号 | 高 | 默认不采集，若出现需遮挡或裁掉 |
| 老师账号信息 | 高 | 不保存，不代替老师登录 |
| 题目标准答案和给分规则 | 中 | 可保存到本地或服务端 |
| AI 建议分和理由 | 中 | 可用于老师复核，默认不公开 |
| 最终分数 | 高 | 第一版不从爱探究读取，不集中保存 |
| API 密钥 | 高 | 只放服务端环境变量，不进 Git |

## 账号与平台边界

必须遵守：

- 老师自己登录爱探究。
- 工具不保存爱探究账号、密码、验证码、短信码。
- 工具不绕过平台权限、验证码、风控或接口限制。
- 没有官方授权时，不把逆向接口作为正式方案。
- 若爱探究或学校明确禁止自动化操作，立即停止相应功能。

允许的低风险做法：

- 在老师授权后捕获本机当前显示的爱探究窗口。
- 只截取当前题目的学生答案区域。
- 输出建议分，老师自行判断是否采纳。

需要额外评估的做法：

- 自动点击或自动录分。
- 批量连续处理大量学生答案。
- 保存学生答案截图用于复盘。
- 给多个老师或学校部署。
- 调用境外或第三方 AI 服务处理学生图片。

禁止的做法：

- 保存老师密码。
- 伪造登录或绕过验证码。
- 未经授权抓取接口。
- 静默录屏或后台截屏。
- 自动提交无法追溯的分数。
- 把学生答卷用于模型训练或产品宣传。

## 隐私保护措施

第一版必须实现：

- 捕获前显示明确提示：将读取所选窗口画面。
- 每次浏览器捕获由老师主动发起。
- 只上传裁剪后的答案区域。
- 上传前在前端预览裁剪图。
- 默认不保存图片原件。
- 服务端日志不记录图片内容和完整个人标识。
- API 密钥只存在服务端 `.env`。

建议实现：

- 自动遮挡答案区域上方的姓名栏。
- 图片上传前压缩和裁边，减少无关信息。
- 图片处理完成后立即删除临时文件。
- 若需要保存样本，使用匿名编号并单独取得授权。
- 所有请求使用 HTTPS。
- 后端限流，避免误批量上传。

## 数据保留策略

默认策略：

- 答题图片：处理后立即删除。
- AI 请求日志：只保留时间、题目编号、模型版本、建议分、置信度、错误码。
- 评分规则：由老师主动保存，支持删除。
- 本地配置：只保存裁剪区域、题目配置，不保存账号密码。

若要保存截图用于复盘：

- 必须明确告知保存目的。
- 必须设置保存期限。
- 必须允许删除。
- 必须去除姓名、班级、学号等身份信息。
- 必须限制访问权限。

## API 密钥安全

必须遵守：

- 不把 API key 写进前端 JS。
- 不把 API key 写进 README、截图、聊天记录或 Issue。
- 不提交 `.env`。
- 后端通过环境变量读取 key。
- 前端只调用自己的后端接口。

当前仓库已经：

- 用 `.gitignore` 忽略 `.env`。
- 用 `.env.example` 提供配置模板。

重要提醒：

- 之前已经在对话里出现过真实 API key，应立即到服务商后台撤销并重新生成。
- 轮换后只把新 key 写入本地 `.env`。

## AI 服务边界

第一版规则：

- AI 只给“建议分”，不能替代老师最终判断。
- 必须展示扣分理由和置信度。
- 低置信度必须提示人工复核。
- 不把 AI 输出直接写回爱探究。
- 不使用学生答题图片训练模型，除非另行完成授权和合规评估。

如果工具对外提供给其他老师使用：

- 需要隐私政策或数据处理说明。
- 需要明确第三方 AI 服务商及数据处理方式。
- 需要处理用户删除、查询、更正等请求。
- 需要确认是否触发生成式人工智能服务相关备案、安全评估或其他监管要求。

## 安全审计清单

每次发布前检查：

- `git status` 中没有 `.env`。
- 没有硬编码 API key。
- 没有真实学生图片进入仓库。
- 没有老师账号密码进入日志。
- 后端接口有鉴权或本地访问限制。
- 上传图片大小有限制。
- 错误日志不打印完整图片、token、cookie。
- 捕获权限必须由老师主动点击触发。
- 自动化功能默认关闭。
