# 网页端自动化设计

## 推荐架构

- 前端：窗口捕获、答案区域裁剪、规则输入、结果展示、坐标记录和自动流程控制。
- Node 本地服务：静态网页服务、健康检查、请求代理。
- Python 本地 API：模型调用、图片上传适配、鼠标坐标读取和点击。
- 模型接口：单张答案图加文字规则，返回结构化 JSON。

## 截图和裁剪

使用浏览器 `getDisplayMedia()` 让用户主动选择阅卷窗口。用户首次框选答案区域后，后续同一道题可以复用裁剪区域。

实现要点：

- 裁剪输出可适度放大，提升模型识别稳定性。
- 每次自动评分前刷新当前裁剪图。
- 裁剪失败时暂停自动流程。
- 不从后台静默读取屏幕。

## 自动流程状态机

建议状态：

- `idle`：未启动。
- `running`：自动批卷中。
- `paused`：等待人工处理。

关键机制：

- 每次启动或继续生成新的运行 ID。
- 模型请求返回后先检查运行 ID 是否仍有效。
- 如果用户暂停，旧请求返回不得触发点击。

## 点击规则

- 高置信度：点击对应分数按钮。
- 阅卷系统点分后自动翻页：不再额外点击下一份。
- 低置信度等待审核：暂停并保留当前结果。
- 低置信度自动跳过：点击用户记录的跳过坐标。

## 翻页后刷新

翻页后截图延迟用于等待阅卷系统页面切换，不用于等待模型返回。单位建议面向用户显示为秒，内部换算为毫秒。

后续可升级为页面变化检测：

- 对比裁剪区域像素摘要。
- 等待画面稳定后再截图。
- 超时后暂停并提示用户检查页面。
