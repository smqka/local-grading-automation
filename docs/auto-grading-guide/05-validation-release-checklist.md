# 验证和发布清单

## 功能检查

- 能启动网页服务和评分 API。
- 健康检查正常。
- 能捕获窗口并框选答案区域。
- 能手动输入标准答案和给分规则。
- 能返回建议分、置信度和复核提示。
- 能记录分值坐标。
- 高置信度时只点击分数按钮。
- 低置信度等待审核时会暂停。
- 低置信度自动跳过时会点击跳过坐标。

## 安全检查

- 模型返回前不会点击。
- 暂停后旧请求返回不会点击。
- 自动点击默认关闭。
- 鼠标接口只绑定本机。
- `.env` 未提交。
- 日志未提交。
- 仓库没有真实学生图片或阅卷系统截图。

## 兼容检查

- 模型接口支持图片输入。
- 若使用图片 URL 模式，URL 可被模型网关访问。
- 翻页后截图延迟足以覆盖阅卷系统页面切换。
- 不同屏幕缩放下坐标记录仍可用。

## 发布检查

- README 是通用中文说明。
- Skill 文件夹可通过校验。
- `.env.example` 只有占位符。
- `.gitignore` 覆盖 `.env`、日志、缓存和构建输出。
- 测试命令通过：

```powershell
npm.cmd run check
python -m unittest discover -s tests
```
