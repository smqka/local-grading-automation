# MVP 试用步骤

版本日期：2026-06-12

本步骤用于本机试用当前 MVP。工具只输出建议分，老师仍需在爱探究中手动确认和录分。

## 试用前检查

- `.env` 已存在，且包含 `OPENAI_API_KEY`。
- 电脑微信或浏览器能打开爱探究批阅页面。
- 浏览器使用 Chrome 或 Edge。
- 当前试用题目有满分、标准答案和给分规则。
- 截取画面不要包含姓名、班级、学号、聊天消息或分数输入区。

## 启动服务

启动评分 API：

```powershell
C:\Users\Administrator\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe -m grading_api.server
```

另开终端启动网页服务：

```powershell
node server/index.js
```

打开：

```text
http://localhost:5173
```

## 健康检查

```powershell
Invoke-RestMethod http://127.0.0.1:8765/health
Invoke-RestMethod http://127.0.0.1:5173/api/health
```

网页右上角应显示“服务正常”。如果显示“评分 API 未启动”，先检查 Python 服务是否还在运行。

## 试用流程

1. 在爱探究中打开需要批阅的题目。
2. 在工具网页点击“开始捕获”。
3. 在浏览器弹窗中选择爱探究窗口。
4. 在预览画面中拖拽框选学生答案区域。
5. 检查裁剪预览，只保留学生答案。
6. 勾选“裁剪图不含姓名、班级或学号”。
7. 填写满分、标准答案和给分规则，也可以补充扣分规则。
8. 点击“获取建议分”。
9. 查看建议分、扣分点、置信度和复核提示。
10. 老师自行在爱探究里确认并手动录分。

## 暂停条件

出现以下情况时不要使用建议分：

- 裁剪图包含学生身份信息。
- 答案图模糊、截错区域或包含多题。
- 页面显示低置信度或需要复核。
- 评分 API 报错或超时。
- AI 建议分明显超过题目规则范围。

## 试用记录

建议每次真实试用只选一道题，记录：

- 题型和满分。
- 样本份数。
- AI 建议分和老师最终分差距。
- 高估分样本数量。
- 老师是否认为节省时间。
