# 本地试用步骤

本步骤用于在本机试用当前工具。建议先用非敏感样例或已脱敏答案图验证流程，再进入真实批阅场景。

## 试用前检查

- 已安装 Node.js 20+ 和 Python 3.10+。
- `.env` 已存在，且包含可用的模型 API 配置。
- 浏览器使用 Chrome 或 Edge。
- 阅卷系统页面能在本机打开。
- 当前题目有满分、标准答案和给分规则。
- 答案区域、分数按钮和跳过按钮位置相对稳定。

## 启动服务

```powershell
scripts\start-local-tool.cmd
```

打开：

```text
http://127.0.0.1:5175
```

## 健康检查

```powershell
Invoke-RestMethod http://127.0.0.1:8765/health
Invoke-RestMethod http://127.0.0.1:5175/api/health
```

网页右上角应显示服务正常。

## 手动评分试用

1. 在阅卷系统中打开需要批阅的题目。
2. 在工具网页点击“开始捕获”。
3. 在浏览器弹窗中选择阅卷系统窗口。
4. 在预览画面中拖拽框选学生答案区域。
5. 填写满分、标准答案和给分规则。
6. 点击“获取建议分”。
7. 人工核对建议分、置信度和不确定因素。

## 自动批卷试用

1. 先完成一次手动评分，确认截图、规则和模型输出正常。
2. 记录每个分值按钮坐标。
3. 如需低置信度自动跳过，记录跳过按钮坐标。
4. 设置置信度阈值。
5. 设置低于阈值时等待审核或自动跳过。
6. 设置翻页后截图延迟。
7. 点击“开始批卷”。

## 暂停条件

出现以下情况时应暂停：

- 截图区域错误、模糊或包含多题。
- 分数按钮坐标记录错误。
- 阅卷系统页面切换明显慢于设置的截图延迟。
- 模型建议分明显不符合规则。
- 评分 API 报错、超时或网关不支持图片输入。

## 试用记录

建议记录：

- 题型和满分。
- 样本份数。
- 自动打分份数。
- 等待审核份数。
- 自动跳过份数。
- AI 建议分和人工最终分差距。
- 需要改进的截图、提示词或规则问题。
